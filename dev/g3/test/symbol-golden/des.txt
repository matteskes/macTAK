# The 2525D/E leg of the symbol golden test (dev/g3/test/SymbolOracle.java,
# make test-symbol-golden): each code is rendered by the kernel's 2525D and
# 2525E providers — what ATAK 5.5 dispatches to by code length — and the
# app's renderer (mactak.engine.Symbols.render) must draw the same codes
# with the same pixels. Nothing here feeds expected/renderable.tsv: the
# kernel's CoT mapping never produces a 2525D/E code, so the Swift port has
# nothing to answer about them (dev/g3/NOTES.md trap #22).
#
# The cases are the kernel's six civilian basic prefixes
# (MilStd2525dSymbologyProviderBase, MIL-STD-2525D 5.3.3) across the
# identity digits, and the 2525E twins: a civilian code fills purple,
# a hostile or suspect one stays red, and the exercise context — the
# provider's Joker and Faker — fills purple, as the provider does.
#
# A 2525D code is 20 digits: version "10", then context (0 reality,
# 1 exercise, 2 simulation), affiliation (0 pending, 3 friend, 5 suspect,
# 6 hostile), symbol set, and the entity code; a 2525E code is 30 digits,
# version "13". The codes below are real symbols (the oracle refuses a
# code mil-sym doesn't know) from the kernel's mil2525cd_csv and mil-sym's
# msd.txt.
